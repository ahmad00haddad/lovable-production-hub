## 💡 فكرة المشروع
تأتي **منصة إدارة الإنتاج** لتحل مشكلة تشتت فرق العمل بين رسائل الواتساب والورق المطبوع أثناء التحضير لأيام التصوير. 
توفر المنصة بيئة مركزية، بسيطة، وسريعة الاستجابة (Real-time) تتيح لمدير المشروع وأفراد الطاقم رؤية كل ما يحتاجونه في مكان واحد: المهام المطلوبة، حالة المعدات، ونسبة الجاهزية الكلية للعمل.

## ✨ الميزات الرئيسية (Features)

- **📊 لوحة تحكم ذكية (Dashboard):** تتبع نسبة الجاهزية الكلية للمشروع (مهام + معدات) لحظة بلحظة مع عد تنازلي لموعد التصوير.
- **👥 إدارة طاقم العمل:** الانضمام للمشروع بكل سهولة عبر "كود قصير" دون تعقيدات تسجيل الدخول، مع إمكانية تصفح المشروع كزائر قبل تحديد الهوية.
- **✅ تتبع المهام (Task Management):** توزيع المهام على أفراد الطاقم أو إضافة "مهام عامة" مشتركة، مع إغلاق تلقائي للوحة المفاتيح لتجربة إدخال مريحة على الهاتف.
- **🎥 إدارة المعدات (Equipment Tracking):** جرد كامل لمعدات التصوير والإضاءة والصوت، مع إمكانية تعديل الكميات وتأكيد جلبها.
- **⏱️ سجل نشاطات حي (Activity Feed):** متابعة مستمرة لما يحدث بالمشروع (من أضاف مهمة، من أكمل تحضير معدة) محدثة بالزمن الفعلي (Real-time) عبر Supabase.
- **📱 تجربة مستخدم فائقة (Premium UX):** 
  - شريط تنقل سفلي (Bottom Tab Navigation) مخصص للهواتف المحمولة.
  - واجهات فارغة (Empty States) مصممة بعناية لتوجيه المستخدم.
  - نوافذ حوار مخصصة وآمنة (Custom Dialogs) للحماية من الحذف بالخطأ، مع معالجة ذكية لحذف البيانات المرتبطة (Cascade Deletion).
  - تصميم عصري يعتمد على الـ Glassmorphism الداكن.

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **واجهة المستخدم (Frontend):** React, Vite, Tailwind CSS, shadcn/ui
- **التوجيه وإدارة الحالة (Routing & State):** TanStack Router, TanStack Query
- **قاعدة البيانات والخدمات الخلفية (Backend/BaaS):** Supabase (Postgres, Realtime)
- **الأيقونات:** Lucide React

## 🚀 البدء السريع (Getting Started)

1. **استنساخ المستودع (Clone the repository):**
   ```bash
   git clone https://github.com/ahmad00haddad/lovable-production-hub.git
   ```

2. **تثبيت الحزم (Install dependencies):**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير (Run development server):**
   ```bash
   npm run dev
   ```
